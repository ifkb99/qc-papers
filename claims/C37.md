# C37 — In table-lookup (Gidney-style) modexp the identity tail is dead, not merely constant: support confined to z_exp on bits {0…α−1}, containing no z with any tail bit set — strictly sharper than C24

**Status.** derived before measuring, then verified 3/3, and at K = 4, 5

## Evidence

live exponent bits exactly [0], [0], [0,1] at (N,a) = (5,4), (7,6), (5,2) with α = 1,1,2, at K = 1 and 2; still exactly {0…α−1} at K = 4 and 5 (q = 29) in both β=1 moduli, so the tail stays dead at any length. Same modulus/base contrast: standard contains the all-ones-tail vector 1_I, lookup contains no tail bit at all **Model validated against arXiv:1905.07682 §3.5 / arXiv:1905.09749**: the joint `table[ei, mi]` indexing we simplified away is harmless (every ke=1 in a tail window ⟹ outer index degenerate).
